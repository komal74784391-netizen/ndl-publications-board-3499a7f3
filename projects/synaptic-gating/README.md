# Synaptic Credit Gating in Recurrent Circuits

Implementation and experiment code for the paper **Synaptic Credit Gating in Recurrent Circuits** (PLOS Computational Biology, 2026).

## Release Status
**Released** - the code in this folder is public and matches the camera-ready version (v1.0.0).

## Layout
- `src/` - core model and training code
- `data/` - example inputs
- `experiments/` - scripts to reproduce the main figures
- `notebooks/` - exploratory analysis
- `results/` - aggregate outputs
- `tests/` - smoke tests

## Citation
Neural Dynamics Lab. "Synaptic Credit Gating in Recurrent Circuits." PLOS Computational Biology, 2026.
